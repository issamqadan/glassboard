# Glassboard — Web shell (M2)

A thin browser front-end over the Rust engine core, compiled to WebAssembly.
No Node/npm required: `wasm-pack` builds the WASM, and Python serves the static
files. All rules, search, and (later) assistance live in the Rust core — this
shell only renders the board and forwards clicks.

## Prerequisites (already installed on the dev machine)

- Rust + `cargo` (rustup)
- `wasm32-unknown-unknown` target: `rustup target add wasm32-unknown-unknown`
- `wasm-pack`: `cargo install wasm-pack`

## Build the WASM package

From `core/bindings`:

```sh
wasm-pack build --target web --out-dir ../../web/pkg
```

This regenerates `web/pkg/` (git-ignored). Rerun it whenever the Rust core or
bindings change.

## Serve

From `web/`:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000> and play — you are White, the engine plays
Black. Pick a piece, then a highlighted square. Change engine strength with the
depth selector.

## Files

- `index.html` — page shell
- `style.css` — board + layout
- `main.js` — loads the WASM `Game` and drives the UI
- `pkg/` — generated by wasm-pack (not committed)
