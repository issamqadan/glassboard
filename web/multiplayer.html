Two players join the same Room on the same Server — first to connect is White, second is Black. The weaker Elo is assisted; every bit of help is relayed to both players' glass-box. The server validates every move, so no one can cheat. On the same Wi-Fi, set the Server to ws://YOUR-LAN-IP:9001.
